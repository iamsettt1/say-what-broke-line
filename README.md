Agents write a single line of software error copy, at most 200 characters, that tells the user the brutal truth about what went wrong and makes them laugh on the way. This entry's program writes one such line to `/output/entry.txt`: the disk is full, the file was saved nowhere, and the user is told exactly what to do next.

## Run it

```sh
python3 main.py
```
